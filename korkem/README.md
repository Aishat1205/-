# Волшебный мир Коркем

Персональная интерактивная библиотека сказок. Главная героиня каждой истории — Коркем (3 года).
Работает в браузере на iPhone, iPad и компьютере, устанавливается на главный экран как PWA.

## Быстрый старт

```bash
cd korkem
npm install
npm run dev          # http://localhost:2233 (в той же сети: http://<IP-компьютера>:2233)
```

Сборка и проверка production-версии (с Service Worker и офлайн-режимом):

```bash
npm run build        # проверка типов + сборка в dist/
npm run preview      # http://localhost:2234
```

Необязательный AI-сервер для генерации сказок:

```bash
cp .env.example .env               # впишите ANTHROPIC_API_KEY (только на сервере!)
export $(grep -v '^#' .env | xargs)
npm run dev:api                    # http://localhost:8787, Vite проксирует /api сюда
```

Без ключа всё работает: сказки создаются из локальных шаблонов, а в настройках честно написано, что AI не подключён.

## Как устроена персонализация

Тексты хранятся с маркерами: `{Name}` и падежи `{Name:gen|dat|acc|ins|pre}`, а слова, зависящие от пола,
пишутся как `{=увидела|увидел}`. Имя подставляется при чтении, поэтому смена имени или пола в профиле
сразу меняет все сказки. Женские имена на согласную (Коркем, Айгерим) по правилам русского языка
не склоняются; мужские склоняются («с Арманом»). Формы можно задать вручную в профиле.

Добавить сказку: создайте файл в `src/data/stories/` по образцу и добавьте её в `index.ts`.
Каждой сцене нужен текст и `illustration` (локация, время суток, поза героини, персонажи, эффекты).

## Что работает локально (без внешних сервисов)

- 8 полноценных сказок по 13–16 сцен, у каждой сцены своя иллюстрация.
- Чтение по сценам: свайпы, клавиши ←/→, прогресс, автосохранение места, экран окончания.
- Режимы «Читать самой» и «Читать ребёнку» (крупный текст, три большие кнопки), режим «Перед сном».
- Озвучивание через Web Speech API: старт, пауза, продолжение, стоп, повтор сцены, выбор голоса,
  скорость, громкость (кроме iOS), автопереход после окончания озвучивания (можно выключить).
- «Папа читает»: запись голоса для каждой сцены, прослушивание, перезапись, удаление; при чтении
  вместо синтезатора звучит запись.
- Фоновая музыка: три оригинальные колыбельные, громкость, плавное появление и затухание,
  автоостановка в конце сказки. Включается только по нажатию.
- Генератор сказок: 10 тем × 5 настроений × 3 длины × 8 видов морали × 10 спутников, учёт
  ключевых слов из пожеланий. Подпись честно указывает: «Собрана на устройстве из локальных шаблонов».
- Избранное, история, настройки, профиль, фото (необязательно, только на устройстве).
- PWA: установка на главный экран, офлайн-работа после первого открытия.

## Что требует внешнего API

- **AI-генерация текста сказок** — нужен `ANTHROPIC_API_KEY` на сервере (`server/storyAi.ts`,
  модель задаётся `STORY_MODEL`). На сервер не отправляются имя, фото и записи голоса — только тема,
  настроение, возраст, пол, выбранные спутники и текст пожеланий. Модель пишет текст с маркерами имени.
- **Генерация изображений** — подготовлен интерфейс `IllustrationGenerator` и поле `imageUrl` у сцены;
  конкретный сервис не подключён. Эндпоинт `/api/illustrate` локального сервера отвечает 501.
- **Серверный синтез речи** — подключается реализацией интерфейса `SpeechProvider`.

## Офлайн-режим

Без интернета после первого открытия работают: библиотека, иллюстрации, чтение, прогресс, избранное,
генератор шаблонов, музыка, запись голоса и озвучивание голосами, установленными на устройстве.
Требуют интернета: первая загрузка, шрифты при первом открытии, AI-генерация, сетевые голоса синтеза.

## Установка на iPhone

1. Разместите приложение по адресу с **https** (см. «Развёртывание»).
2. Откройте адрес в **Safari**.
3. Нажмите «Поделиться» → «На экран „Домой“» → «Добавить».
4. Приложение «Мир Коркем» откроется на весь экран, без адресной строки.

Важно для iPhone: микрофон доступен только по https; звук (озвучивание и музыка) не слышен
при включённом беззвучном режиме; русский голос можно скачать в «Настройки → Универсальный доступ →
Устный контент → Голоса → Русский».

## Развёртывание

**Vercel** (статический фронтенд + serverless-функции в `api/`):

1. Импортируйте репозиторий, Root Directory — `korkem`.
2. Build Command `npm run build`, Output `dist` (уже указано в `vercel.json`).
3. По желанию добавьте переменную окружения `ANTHROPIC_API_KEY`.

Любой статический хостинг (Netlify, GitHub Pages, Cloudflare Pages) подойдёт для режима без AI:
загрузите `dist/` и настройте перенаправление всех путей на `index.html`.

## Известные ограничения

- Голоса синтеза речи зависят от устройства: в некоторых браузерах русского голоса нет.
- На iOS громкость синтеза речи не регулируется (настройка скрыта), а пауза в редких версиях Safari
  перезапускает текущее предложение.
- AI-генерация проверена до запроса к API (с неверным ключом сервер возвращает понятную ошибку,
  клиент переключается на шаблоны); с действующим ключом в этой среде не запускалась.
- Казахский язык пока не реализован: в настройках он помечен «скоро», модель данных его поддерживает.
- Генерация изображений через внешний сервис не подключена — используются встроенные SVG-иллюстрации.
- Записи голоса занимают место в хранилище браузера; при очистке данных Safari они удаляются.
